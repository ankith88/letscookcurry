# **App Name**: Let's Cook Curry

## Core Features:

- Weekly Recipe Display: Display a curated list of available recipes for the current week.
- Recipe Cart: Enable users to add recipes to a shopping cart for ordering.
- Weekly Order Schedule: Implement a system to limit order placement to Thursdays and reset weekly recipes every Monday.
- User Authentication: Create user profiles with login options via email, Google, or Apple ID.
- Order History: Allow users to reorder from previous orders stored in their profile.
- Recipe Details View: Enable users to view details for each recipe.
- Rating and Comments Submission: Users can add comments, rate the recipes and submit them. The submitted data gets sent to a server.

## Style Guidelines:

- Primary color: Saturated reddish-orange (#f7a832), reflecting the warm, vibrant nature of curries. This creates an inviting and appetizing feel for the app.
- Background color: Light, desaturated orange (#3d4d24), provides a soft backdrop that doesn't distract from the colorful recipes.
- Accent color: A golden yellow (#fdbe5e) adds a touch of richness, complementing the main theme. This can highlight interactive elements such as buttons or notifications.
- Font: 'PT Sans', a humanist sans-serif that offers a balance of modern aesthetics and readability. It suits both headlines and body text.
- Use a set of consistent icons related to cooking, ingredients, and user actions. Simple and clear icons will enhance user navigation.
- Implement a grid layout for displaying recipes, ensuring that each item is clearly visible and easily accessible. Maintain consistency across the app's interface.
- Use subtle animations for actions like adding to the cart or loading new recipes to provide feedback to the user. Ensure animations do not detract from usability.
