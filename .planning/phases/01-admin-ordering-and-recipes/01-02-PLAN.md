# Plan 01-02: Admin Studio (`/admin`), Recipe CRUD, Genkit AI Autofill & Bulk Import

## Objective
Provide a unified `/admin` dashboard protected by the Admin email allowlist where admins can:
1. Toggle **Ordering Process Active / Inactive** (`orderingFeatureEnabled`) with instant visual feedback.
2. Control **Order Status** (`orderWindowMode`: **Turn Orders ON**, **Turn Orders OFF**, or **Auto Schedule Mon–Thu**).
3. Manage the **Admin Email Allowlist** directly from `/admin`.
4. **Add, Edit, Delete, and Toggle Weekly Menu (`isWeekly`)** for recipes in Firestore (`recipes` collection) via:
   - An intuitive **Recipe Form Dialog** (with Firebase Storage image upload or image URL, dynamic ingredients/instructions lists, region/diet/spice/price inputs).
   - **Genkit AI Recipe Autofill** (`src/ai/flows/generate-recipe.ts`) — enter a dish name or rough notes and let Gemini populate all recipe fields automatically.
   - **Bulk JSON / CSV Import** — paste or upload a `.json` or `.csv` file to batch-create recipes in Firestore.
