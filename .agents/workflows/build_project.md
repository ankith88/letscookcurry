# Step 1: Set Working Directory

Ensure you are in the project root directory:
```bash
cd /Users/ankithravindran/Development/Antigravity/letscookcurry
```

# Step 2: Install Dependencies

Install the project's npm dependencies:
```bash
npm install
```

# Step 3: Run TypeScript Typecheck

Verify that there are no TypeScript compilation or type errors:
```bash
npm run typecheck
```

# Step 4: Build Production Bundle

Compile and build the Next.js web application for production:
```bash
npm run build
```
