# Step 1: Set Working Directory

Ensure you are in the project root directory:
```bash
cd /Users/ankithravindran/Development/Antigravity/letscookcurry
```

# Step 2: Start Preview Server

Start the Next.js development server with Turbopack on port 9002:
```bash
npm run dev
```

# Step 3: Verify Application Preview

1. Wait for the server output to indicate `Ready` on `http://localhost:9002`.
2. Open `http://localhost:9002` in your browser.
3. Verify that the "Let's Cook Curry" home page renders cleanly without critical console errors and that navigation and recipe pages work as expected.
